Team control

Assign a prioritised source to a specific team so they can work on those cases first.

! Warning Changes you make here will override any source prioritisation previously set
For example, if you want a particular team to work on Local Authority referrals, select that as the source.
The team selected will first work on referrals from the source you've prioritised. Once there are no longer any referrals from that prioritised source, the team will get referrals as normal from the workbasket.
Once submitted, the changes you've made to any teams' workbasket will take place immediately. To change the priority of a source, remove it from the table and start again.
